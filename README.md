# ADISE25_2021034  
Web API Implementation of the card game **ΞΕΡΗ**

---

## ΠΕΡΙΛΗΨΗ

Το παρόν project αποτελεί μια υλοποίηση του παιχνιδιού καρτών **ΞΕΡΗ**, στα πλαίσια του μαθήματος **ΑΔΙΣΕ**.  
Το παιχνίδι υποστηρίζει δύο παίκτες (**Human–Human**) και ακολουθεί την αρχιτεκτονική **Web API**, χρησιμοποιώντας **PHP, MySQL και AJAX**.

Σύμφωνα με τις απαιτήσεις για ομάδα **ενός ατόμου**, το παιχνίδι μπορεί να παιχτεί εξ ολοκλήρου μέσω **Web API** (π.χ. με χρήση Postman ή CLI).  
Για λόγους ευκολίας δοκιμών και καλύτερης οπτικοποίησης της κατάστασης του παιχνιδιού, έχει υλοποιηθεί και ένα **απλό γραφικό περιβάλλον (GUI)** μέσω browser.

Το GUI **δεν περιέχει λογική παιχνιδιού** και λειτουργεί αποκλειστικά ως client του API, επικοινωνώντας με αυτό μέσω **JSON αιτημάτων**.  
Η κατάσταση του παιχνιδιού αποθηκεύεται πλήρως στη βάση δεδομένων **MySQL**, διασφαλίζοντας τη συνέπεια και την ανεξαρτησία του API από τον τρόπο πρόσβασης (CLI ή browser).

---
## ΡΟΗ ΠΑΙΧΝΙΔΙΟΥ

1. Ο πρώτος παίκτης συνδέεται στο παιχνίδι και αρχικοποιεί το board.  
2. Ο δεύτερος παίκτης συνδέεται και το παιχνίδι ξεκινά.  
3. Οι παίκτες παίζουν εναλλάξ, σύμφωνα με τη σειρά (`p_turn`).  
4. Το API ελέγχει την εγκυρότητα των κινήσεων και εφαρμόζει τους κανόνες του παιχνιδιού.  
5. Αναγνωρίζονται ειδικά γεγονότα (π.χ. ΞΕΡΗ, ΞΕΡΗ με J).  
6. Το παιχνίδι ολοκληρώνεται όταν εξαντληθούν τα φύλλα ή κάποιος κάνει abort.  
7. Υποστηρίζεται επανεκκίνηση του παιχνιδιού μέσω του αντίστοιχου endpoint.

## ΠΕΡΙΓΡΑΦΗ API ENDPOINTS

Όλα τα endpoints:

- Χρησιμοποιούν **JSON** για δεδομένα εισόδου/εξόδου.  
- Επιστρέφουν κατάλληλους **HTTP status codes**.  
- Μπορούν να χρησιμοποιηθούν τόσο από **Postman / CLI** όσο και από το **GUI**.
- Για όλα τα endpoints (εκτός του login) απαιτείται το HTTP header για το authentication.



---

### 1) Σύνδεση Παίκτη

Καταχώρηση παίκτη στο παιχνίδι και απόδοση ρόλου (**P1** ή **P2**).  
Επιστρέφει μοναδικό token αυθεντικοποίησης.

**Endpoint:** `/api/login.php`  
**Method:** `POST`

**Parameters:**
- `username` (string)
- `player_id` (P1 | P2)

**Response:**
- `token` (string)
- `player` (P1 | P2)

---

### 2) Κατάσταση Παιχνιδιού

Επιστρέφει την πλήρη τρέχουσα κατάσταση του παιχνιδιού.

**Endpoint:** `/api/game.php`  
**Method:** `GET`  
**Headers:** `X-TOKEN: <token>`

**Response περιλαμβάνει:**
- Τρέχουσα κατάσταση παιχνιδιού
- Σειρά παίκτη
- Φύλλα στο τραπέζι
- Φύλλα στο χέρι παίκτη
- Μαζεμένα φύλλα
- Σκορ παικτών
- Τελευταίο γεγονός (π.χ. ΞΕΡΗ)

---

### 3) Παίξιμο Κάρτας

Ο παίκτης παίζει ένα φύλλο από το χέρι του.  
Σε περίπτωση άκυρης κίνησης επιστρέφεται μήνυμα σφάλματος.

**Endpoint:** `/api/play_card.php`  
**Method:** `POST`  
**Headers:** `X-TOKEN: <token>`

**Parameters:**
- `card_id` (integer)

---

### 4) Επανεκκίνηση Παιχνιδιού

Επανεκκινεί το παιχνίδι όταν αυτό έχει ολοκληρωθεί.

**Endpoint:** `/api/restart_game.php`  
**Method:** `POST`  
**Headers:** `X-TOKEN: <token>`

---

### 5) Αποσύνδεση Παίκτη

Αποσυνδέει τον παίκτη από το παιχνίδι.  
Αν το παιχνίδι βρίσκεται σε εξέλιξη, ο αντίπαλος κερδίζει αυτόματα.

**Endpoint:** `/api/logout.php`  
**Method:** `POST`  
**Headers:** `X-TOKEN: <token>`

## ΔΟΜΗ ΒΑΣΗΣ ΔΕΔΟΜΕΝΩΝ

### 1) Πίνακας `cards`

Αποθηκεύει όλα τα φύλλα της τράπουλας.

- `card_id` : Μοναδικό ID φύλλου  
- `suit` : Σύμβολο (κούπα, καρό, σπαθί, μπαστούνι)  
- `value` : Αξία φύλλου  
- `location` : deck, table, hand_P1, hand_P2, captured_P1, captured_P2  
- `table_order` : Σειρά φύλλων στο τραπέζι (NULL για φύλλα εκτός τραπεζιού)

---

### 2) Πίνακας `players`

Αποθηκεύει τις πληροφορίες των παικτών.

- `player_id` : P1 ή P2  
- `username` : Όνομα παίκτη  
- `token` : Token αυθεντικοποίησης  
- `last_action` : Χρόνος τελευταίας ενέργειας  
- `xeri_count` : Αριθμός ξερών  
- `xeri_j_count` : Αριθμός ξερών με J  
- `last_seen` : Τελευταία παρουσία online

---

### 3) Πίνακας `game_status`

Γενική κατάσταση παιχνιδιού.

- `status` : not active, started, ended, aborted  
- `p_turn` : Σειρά παίκτη  
- `result` : Νικητής (P1 ή P2)  
- `last_event` : Τελευταίο γεγονός (π.χ. ΞΕΡΗ)  
- `last_change` : Χρόνος τελευταίας αλλαγής  
- `p1_score` : Σκορ P1  
- `p2_score` : Σκορ P2  
- `last_capturer` : Παίκτης που μάζεψε τελευταία φορά
